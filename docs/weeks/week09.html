Week 9 — Patterns inside Patterns

Nested loops, state at different levels, reset points, and accumulation

TipThis week’s central question

What changes when one repeated process contains another repeated process?

Learning goals

By the end of this week, you should be able to:

  1. trace nested loops;
  2. distinguish outer-loop state from inner-loop state;
  3. decide where an accumulator should be initialized;
  4. use names such as branch_total and company_total to make state scope visible;
  5. explain reset, accumulation, and overwrite errors;
  6. verify multi-level repetition with a small hand-worked case.

Connection

Week 8 introduced repeated state. Week 9 introduces state at more than one level.

Names now do conceptual work: branch_total describes state that resets for each branch, while company_total describes state that survives across branches.

Debug This

An assistant moved branch_total = 0 outside the outer loop:

company_total = 0
branch_total = 0

for branch in range(1, 3):
    for day in range(1, 4):
        daily_sales = float(input("Sales: "))
        branch_total += daily_sales

    company_total += branch_total

print(f"Company total: {company_total:.2f}")

Use:

  • Branch 1: 100, 120, 80
  • Branch 2: 90, 110, 130

Do not run yet.

  1. Predict the final value of company_total.
  2. Trace branch_total after each branch.
  3. Explain why the result becomes 930 instead of 630.
  4. Identify which state must reset for each branch.

The problem is state leakage and double counting, not information loss.

AI Verify

Now examine a different silent bug:

company_total = 0

for branch in range(1, 3):
    branch_total = 0

    for day in range(1, 4):
        daily_sales = float(input("Sales: "))
        branch_total += daily_sales

    company_total = branch_total

print(f"Company total: {company_total:.2f}")

With the same values, the correct total is 630.

  1. Predict the final value.
  2. Run the program.
  3. Diagnose why assignment overwrites prior branch information.
  4. Fix & verify by accumulating rather than replacing.
