DSA105 · TRACE Studio · Thinking, Reasoning, Algorithms, Coding & Execution

Official course: Fundamentals of Algorithms and Programming · BSc in Data Science and Analytics · English · Compulsory · 5 ECTS

A computational learning studio

DSA105 is the first course in a two-semester computational foundations sequence.

Python is used as a concrete, executable representation of computational ideas while the course progressively develops problem solving, algorithm design, testing, debugging, and domain transfer.

Core learning cycle: Predict → Run → Modify → Explain → Build → Test

ImportantAbout this site

TRACE Studio is the interactive learning environment used alongside DSA105.
It is not a replacement for the university’s official course catalogue, regulations, or assessment announcements. When there is any discrepancy, the official university information takes precedence.

Official course objective

The course aims to develop basic computer-based problem-solving skills by focusing on algorithm development, flowcharting, and programming logic. Python is used as the primary implementation language. Students work with data types, control structures, functions, and file operations, with examples connected to economics, business, and data analysis. Through hands-on exercises, students practice designing, implementing, testing, and debugging programs while building a foundation for advanced data structures and algorithmic thinking.

Learning outcomes

By the end of DSA105, you should be able to:

  1. Define computational problems.
  2. Design algorithms for problem solving.
  3. Translate algorithms into Python code.
  4. Test and debug programs effectively.
  5. Integrate programming with economics and business analytics contexts.
NoteWhat this course is not

This is not a course in memorizing Python commands. Python gives us a visible and executable way to test whether our reasoning is precise enough for a computer.

How the course works

1. Concept

A problem, computational pattern, or domain scenario is introduced.

2. Action

You predict, trace, modify, complete, or build something in Colab.

3. Evidence

A short quiz, lab task, exit ticket, or homework records what you can do.

4. Feedback

Your evidence is combined into a learning portfolio after the midterm.

Weekly evidence model

Each teaching week uses a small number of recurring evidence points:

  • Weekly Quiz — short individual retrieval and diagnostic check.
  • Lab Evidence — one selected in-class production.
  • Exit Ticket — concept check, difficulty signal, and confidence rating.
  • Homework — a near-transfer problem using the week’s computational pattern.

Your portfolio emphasizes development across skills, not only raw scores.
